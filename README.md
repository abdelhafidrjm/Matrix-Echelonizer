# Matrix Echelonizer

Ce programme transforment les matrices en leur forme d’échelon en utilisant l’élimination de Gauss en ligne.

[Version python](/echelon.py)  
[Version C](/echelon.c)

## Example:

-------matrice-------  
|0.00||1.00||2.00|  
---------------------  
|7.00||0.00||4.00|  
---------------------  
|0.00||5.00||6.00|  
---------------------  
  
--matrice échelonnée-  
|7.00||0.00|| 4.00|  
---------------------  
|0.00||1.00|| 2.00|  
---------------------  
|0.00||0.00||-4.00|  
---------------------
