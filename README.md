# Math Projects

Ce répertoire contient des programmes qui ont une relation avec les mathématiques, ce sont des programmes personnels. Je l'ai fait pour développer mes compétences dans l'application des mathématiques en utilisant l'algorithmie

## Matrix Echelonizer

Le programme transforment les matrices en leur forme d’échelon en utilisant l’élimination gaussienne en ligne.  

[Version python](/Echelonizer/Echelonizer.py)  
[Version C](/Echelonizer/Echelonizer.c)  

### Example: 

-------matrice-------  
|+0.00||+1.00||+2.00|  
---------------------  
|+7.00||+0.00||+4.00|  
---------------------  
|+0.00||+5.00||+6.00|  
---------------------  
  
--matrice échelonnée-  
|+7.00||+0.00||+4.00|  
---------------------  
|+0.00||+1.00||+2.00|  
---------------------  
|+0.00||+0.00||-4.00|  
---------------------
